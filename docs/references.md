# 公开项目参考

这些项目仅作为产品与架构参考，不复制其代码或界面。

- [InvenTree](https://github.com/inventree/InvenTree)：参考可审计的库存控制、零件/物料追踪，以及 Web API 与客户端分层。
- [Inventory Store](https://github.com/JTCozart/inventory-store)：参考分类、标签、库存阈值、库存调整历史和 CSV 导入导出等小型库存产品能力。
- [riigait/ims](https://github.com/riigait/ims)：参考 React、TypeScript、PostgreSQL、Prisma 等分层库存系统的组织方式；本项目不采用其多部门、角色和审批范围。

本项目首版刻意保持更小的范围：单用户、材料/作品/成品闭环，以及支持未来多客户端的 REST API。
