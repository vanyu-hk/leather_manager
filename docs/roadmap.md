# 实施路线图

## 里程碑 1：项目底座

- 初始化 React + Vite Web 工程与 NestJS API 工程。
- 建立 PostgreSQL 连接、迁移、环境配置和本地开发容器。
- 接入图片上传与对象存储抽象，建立备份脚本与部署说明。

## 里程碑 2：材料库存

- 材料类型、颜色、单位、图片和库存阈值。
- 材料新增、编辑、筛选、调整、删除限制与库存变动历史。

## 里程碑 3：作品与领料

- 作品状态看板、说明与图片。
- 领料、库存扣减、库存不足拦截、修改/撤销回补和原子事务。

## 里程碑 4：成品与仪表盘

- 完成作品生成成品档案、材料溯源和成品筛选。
- 仪表盘统计、低库存提醒和响应式移动端体验。

## 里程碑 5：上线与扩展

- 部署、备份恢复演练、监控和发布检查。
- 评估小程序客户端、采购批次、成本统计和销售管理的优先级。
